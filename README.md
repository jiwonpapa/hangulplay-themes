## 폰·태블릿 배경 분리 · 앱0.11.26/code57 이상

기본 종이와 우주·바다·할로윈·공룡·크리스마스가 각각 세로/가로 구도를 사용합니다. v3 팩에는 전용 background-portrait.png와 background-landscape.png를 함께 제공합니다. 화면 회전·분할 화면에서는 실제 표시 영역의 비율로 선택하며, 장식을 가운데 확대 잘라내지 않고 종이 중간 영역으로 비율 차이를 흡수합니다.

- `catalog-v3/catalog.json`: code57 이상. 외부 할로윈/공룡/크리스마스v3 서명 목록입니다.
- 우주·바다v3는 앱에 내장되며 이전에 선택한 내장 테마는 업데이트 후 같은 테마의 새 구도로 이어집니다.
- 외부 테마는 설정 → 배경과 친구 꾸미기 → 목록 새로고침 → 업데이트로 새 파일쌍을 받습니다.
- 기존 v1/v2 목록·ZIP은 원본 그대로 보존합니다. 움직임/친구 반응·필기·학습 자료 정책은 유지합니다.

## 배포 채널

- `catalog-v2/catalog.json`: 앱code56부터 사용하는 서명 목록. 새 optional `reactions.png`와 `motion.background` 선언을 지원합니다.
- `catalog-v1/catalog.json`: 기존 앱과 할로윈v1/공룡v1을 위한 보존 채널. 원본 목록·Release ZIP을 변경하지 않습니다.
- 기본·우주·바다는 오프라인 내장입니다. 추가팩도 설치 후에는 오프라인으로 사용하며 내장팩은 삭제하지 않습니다.

목록/ZIP/썸네일은 고정 버전URL·SHA256·크기·ECDSA 서명·호환 버전을 검사합니다. 설치 실패/중단 시 이전 테마를 유지합니다. 학습 자료 업데이트나 APK 배포 채널과는 별개입니다. 아동 정보·학습 기록·앱 코드는 이 저장소로 전송하지 않습니다.

## 파일 계약

ZIP 최상위: `theme.json`, `background.png`, `companions.png`, `trace.png`, `thumbnail.png`, `CREDITS.md`, 선택 파일 `reactions.png`.

- 배경 중앙은 밝게 비우고, 동적 장식은 native allowlist인 leaves/stars/bubbles/fireflies/snow만 사용합니다. 외부 실행 코드를 받지 않습니다.
- 친구/반응: 토끼·곰·고양이·강아지·펭귄 순서의 투명5칸 atlas. 반응 이미지는 실제 윙크 표정입니다.
- 경로 아이템:4열×4행 정사각형 투명 atlas. 번호·방향·자형·획 판정·학습 기록은 공통입니다.
- palette4쌍의 글자 대비4.5 이상, PNG·압축 경로/크기·hash를 검증합니다.

## 제작·사용 범위

프로젝트 자체5친구와 의상/표정만 참조한 built-in OpenAI ImageGen 원본입니다. 우주/바다/할로윈 경로 아이템은 자체 Blender 원본, 공룡/크리스마스는 ImageGen 원본입니다. 배경·제작 프롬프트·출처/hash를 별도 원본 저장소에 보존합니다. 사람/상용 권리 검수 완료를 주장하지 않습니다. 이 앱에서 사용하도록 배포하며 다른 제품에서 재사용·재배포하려면 별도 허락이 필요합니다. 패키지별 CREDITS.md를 확인하십시오.
